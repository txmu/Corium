# Corium 精简算法模型

运行：`bash formal/check_all_formal.sh`（在仓库根目录，Lean 4.19.0；仅依赖 Init）。

新增源码对应模型位于 `Implementation.lean` 和 `Refinements.lean`。
原 `Models.lean` 保留为首轮简化模型，不代表生产实现。
具体对应、已证明性质、源码修复和未覆盖项见 [COVERAGE.md](COVERAGE.md)。

首轮证明没有修改生产源码。后续按用户授权修复 Merkle/IBC 问题；仍没有
Bash/Python/SQL 到 Lean 的机械等价证明，不能宣称完整源码符合性。

| 模型 | 已证明 | 范围 |
|---|---|---|
| 拓扑排序 | 搜索返回的顺序通过依赖检查且无重复；候选中存在合法顺序则搜索成功 | 用有限候选穷举替代 Kahn；候选全集生成、包过滤与 slot 解析未建模 |
| Exodus quorum | 两个严格超过 2/3 的集合，其交集权重严格超过 1/3；恰好 2/3 不达标 | 自然数权重；同一快照；集合并集权重不超过总量；不证明签名或身份去重实现 |
| 语义状态 | 本地字段无关；任意行置换不改变规范状态 | 用保留字段的多重集表示状态；不证明实际 JSON、schema 或 BLOB 编码 |
| XOR | 单 bit 对称；256 bit 向量逐位 XOR 全零当且仅当 ID 相同 | 不包含十六进制解析、数值距离排序或 DHT 协议 |
| Merkle | 从任意树及其叶到根方向的兄弟路径重构，得到对应包装树的根 | 任意二元 hash；无密码学安全假设；不包含生产路径生成与奇数节点规则 |
| replay/reorg | 分段重放等于一次重放；从共同前缀重组等于目标历史重放 | 纯确定性状态转移；不证明交易验证、共同祖先查找或实际回滚 |
| 事务恢复 | 未提交写入恢复旧值；提交后保留新值；恢复幂等 | 单层事务、理想原子操作；不包含磁盘、并发、嵌套事务与断电 |

所有递归按有限列表结构终止。模型没有 `sorry` 或自定义 `axiom`。
首轮 17 个定理已用 Lean 4.19.0 检查通过；新增证明使用相同版本与公理审计。
核心定理的公理审计仅出现 Lean 标准的 `propext`、`Quot.sound`，或无公理依赖。
这些是首轮核心性质，不能据此宣称相应生产模块已被完整验证。

完整入口检查九个模块；旧入口转发至完整入口。精确定理声明及前提由 [THEOREMS.md](THEOREMS.md) 自动生成并检查漂移。
